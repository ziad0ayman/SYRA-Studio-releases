# SYRA Studio releases

Release files for SYRA Studio, a video editor for the SYRA team. This repository holds no code.

- **FFmpeg source**: SYRA Studio installs FFmpeg and ffprobe and runs them as separate programs. The complete source of
  that exact build is a release here, as FFmpeg's licence asks:
  [ffmpeg-source-n8.1.3-18-g46d899d7a0](https://github.com/ziad0ayman/SYRA-Studio-releases/releases/tag/ffmpeg-source-n8.1.3-18-g46d899d7a0).
  The installed app's `resources\licenses\FFMPEG-SOURCE.txt` points here.
- **Installers and updates**: coming.
